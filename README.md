# Laundry Service Hero Section

This is a simple laundry service website created using HTML and CSS.

## About the Project

The purpose of this project is to create a clean and simple hero section for a laundry service website.

The page includes a navigation bar and a hero section with information about the laundry service.

## Features

- Simple navigation bar
- Logo on the left side
- Navigation links in the center
- Username button on the right side
- Hero section with heading and description
- "Book a Service Today" button
- Laundry-related image
- Clean and simple design
- Uses inline-block for the layout
- No Flexbox used
- Uses viewport units for the hero section

## Technologies Used

- HTML
- CSS
